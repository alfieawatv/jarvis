# JARVIS — Cinematic AI Assistant HUD

Premium Iron Man-style J.A.R.V.I.S. interface.

**Stack:** React + TypeScript + Vite + Framer Motion

## Deploy to Vercel

1. Import this repo on [vercel.com](https://vercel.com)
2. Framework Preset: **Vite**
3. Deploy

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Features

- Cinematic boot + Arc Reactor
- 4 themes
- Draggable widgets
- Voice input
- Camera, Notes, Image Gen, PDF, Home Assistant panels
- Settings for OpenAI / ElevenLabs / Ollama / HA
